# Galera

Taller letterpress de barrio. El cliente compra un **bono de 7 días**, sella cada jornada y enseña un **QR real** en el umbral. No hay retención de franja de 15 minutos.

- Frontend: Angular 22 (signals, zoneless)
- Backend: NestJS 11 + TypeORM + SQLite (Neon-ready)
- Demo: `ines@galera.test` / `galera123` · staff: `staff@galera.test` / `galera123`
- Puerto API: **3077**

**Núcleo B2C:** bono-checkin. Loop hueco+hold+QR: no (Bancal/Gambito/Huella 25–27 ago).
